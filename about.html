About BinaryLab

Project goal

Help beginners understand number systems by letting them experiment with bits instead of only reading about them.

HTML concepts used

  • Semantic tags: header, nav, main, section, article, footer
  • Forms, labels, checkboxes, radio buttons
  • Tables, lists, details and summary
  • Images and links across multiple pages

CSS concepts used

  • Flexbox and grid layouts
  • Custom properties and responsive media queries
  • Pseudo-classes such as :checked and :has()
  • CSS counters and @counter-style

Pages in this website

Home, About, Create Account, Sign In, Dashboard, Learn, Converter and Practice. The account forms are a front-end demo: they validate input but do not store data, because there is no server.
